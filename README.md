# 摸鱼牌社

在原「欢乐斗地主」基础上升级的纯前端单机斗地主。保留原生 JavaScript 和绿色牌桌，新增完整的入座、对局、辅助、结算与本地战绩体验。

**无需账户，不连接后端，不涉及真实财物。** 页面运行不依赖第三方库、字体或图片 CDN。

## 快速开始

直接用浏览器打开 `index.html`，或使用本地预览服务：

```bash
npm start
```

访问 http://127.0.0.1:8088 。启动服务只使用 Node.js 内置模块，无需先安装依赖。如果端口被占用：

```bash
PORT=8089 npm start
```

也可使用 `python3 -m http.server 8088 --bind 127.0.0.1`。本地战绩与设置按浏览器和访问地址分别保存，直接打开文件与 HTTP 预览的数据互不保证共享。

## 这次升级

- **更完整的牌社界面**：暖色背景、绿色纹理牌桌、原创 SVG 人物头像、扑克牌入场、独立开局入口、桌面辅助侧栏。
- **手机和平板布局**：取消旧版 1000px 最小宽度限制；手牌间距、角标字号根据张数自动调整，20 张手牌也能完整呈现。
- **记牌小助手**：只根据你的手牌和已公开打出的牌计算，不偷看 AI 手牌；开局前不显示虚假的牌数。
- **牌局动态**：记录叫地主、出牌、不出和结算，最新操作在上方，最多展示 80 条。
- **托管与提示**：随时开启或收回托管；合法牌型循环提示，选牌后显示牌型及能否压过上家。
- **本地战绩**：休闲积分、对局数、胜率、当前及最高连胜、最近 20 局记录，使用 `localStorage` 保存。
- **完整结算**：底分 10，地主输赢双倍，炸弹与王炸各翻倍，春天及反春天翻倍；结算展示剩余手牌。
- **可保存的偏好**：音效、减少动画、15/30/60 秒出牌时间、普通或快速 AI 节奏；默认 30 秒，从容练习。
- **规则与键盘操作**：内置完整规则，按钮焦点、卡牌键盘选中、选牌状态辅助信息。
- **暂停与重开保护**：打开规则/设置/战绩，或页面进入后台时暂停回合与倒计时；重开需要确认并取消旧局延时任务。

## 游戏规则

### 叫地主

每人 17 张，另留 3 张保密底牌。随机选择起始叫牌者，依次选择是否叫地主。**首位叫牌者成为地主**，获得底牌并先手出牌；三人均不叫则重新发牌。这是简化叫地主规则，不是三分竞叫或多轮抢地主。

### 出牌

顺序为你 → 阿橘 → 老 K。后手必须打出更大的同牌型、同长度组合，也可选择不出。连续两家不出，最后出牌者重新获得自由出牌权。

支持单张、对子、三张、三带一、三带对、顺子、连对、飞机、飞机带单、飞机带对、四带二、四带两对、炸弹和王炸。

- 大小：3 < 4 < … < K < A < 2 < 小王 < 大王。
- 顺子至少 5 张，连对至少 3 对，飞机至少 2 组；均不能含 2 和王。
- 本桌飞机单翼采用**不同点数单牌**规则；飞机双翼须不同点数的对子。
- 四带二可以带两张单牌或一对；四带两对需要两个不同点数的对子。
- 炸弹压普通牌，炸弹之间比点数；王炸最大。
- 农民共享胜负，AI 会考虑队友出牌、对手剩余张数及保留炸弹。

### 积分

基础积分为 `10 × 最终倍数`。你是地主时乘以 2，否则乘以 1；胜方增加、败方扣除相同积分。新设备初始 1,000 分，允许负分，不影响继续游玩。

地主获胜且两位农民均未出过牌为「春天」；农民获胜且地主只出过一手为「反春天」。炸弹、王炸、春天/反春天均各翻一倍。未完成或主动重开的牌局不计战绩。

### 快捷键

| 按键            | 操作                     |
| --------------- | ------------------------ |
| `H`             | 下一组合法提示           |
| `P`             | 不出（自由出牌时不可用） |
| `Enter`         | 打出当前选择             |
| `Esc`           | 取消选牌 / 关闭弹窗      |
| `Tab` + `Space` | 聚焦卡牌并切换选择       |

超时由 AI 代走当前一手，不会自动开启持续托管。托管按钮可单独开启持续代打。

## 开发与测试

建议使用 Node.js 24 或更新版本（也支持 Node.js 22.13+）。开发依赖仅用于测试与格式化，不参与页面运行。

```bash
npm install
npm test
npm run check
```

测试覆盖：54 张牌发牌唯一性、14 类牌型、非法出牌与越权操作、牌型候选有效性、叫地主与底牌保密、两次过牌重置、记牌数据边界、暂停/恢复、旧回调清理、托管、战绩保存、炸弹与春天计分、AI 队友协作，以及 100 局自动模拟对战。

```text
doudizhu/
├── index.html           页面结构、图标和弹窗
├── styles.css           视觉样式与响应式布局
├── game.js              牌型规则、AI、状态机与界面交互
├── favicon.svg          本地图标
├── scripts/serve.mjs    零依赖本地预览服务器
├── tests/game.test.mjs  Node.js + jsdom 自动化回归测试
└── package.json
```

核心类沿用原项目的 `SoundManager`、`Card`、`Deck`、`Player` 和 `GameController`。`HandEvaluator` 是牌型合法性的单一来源，AI 和提示生成的候选都经过它重新校验。

## 边界

这是**单机 AI 对战**，不是联网多人房间。战绩仅保存在当前浏览器，不提供账户同步、真实货币功能或服务端防作弊。AI 是规则启发式策略，而非专业搜索引擎。清除浏览器数据会同时清除本地战绩和偏好。
